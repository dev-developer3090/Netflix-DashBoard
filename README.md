🎬 1. Project Title / Headline
Netflix Content Analytics Dashboard
An interactive Power BI dashboard designed to analyze Netflix's global content library, uncovering trends in movies, TV shows, genres, ratings, release years, and worldwide content availability.

📖 2. Short Description / Purpose

The Netflix Content Analytics Dashboard is an interactive Business Intelligence solution built using Power BI to analyze Netflix's Movies and TV Shows dataset. It enables users to explore content trends, compare ratings, discover popular genres, and analyze global content distribution through dynamic and intuitive visualizations.

🛠️ 3. Tech Stack

The dashboard was built using the following tools and technologies:

📊 Power BI Desktop – Used to create interactive dashboards and visualizations.
🔄 Power Query – Used for data cleaning, transformation, and shaping.
🧠 DAX (Data Analysis Expressions) – Used for calculated columns, measures, and dynamic reporting.
🗄️ MySQL – Used for data preprocessing and querying before visualization.
📑 Microsoft Excel – Used for initial data inspection, formatting, and validation.
🔗 Data Modeling – Relationships between multiple tables enabled efficient filtering and analysis.

📂 4. Data Source

✨ 5. Features / Highlights

📌 Business Problem

Netflix hosts thousands of Movies and TV Shows across different countries and genres. However, extracting meaningful insights from raw datasets is difficult without effective visualization.

Questions such as:

How has Netflix's content library grown over the years?
Which ratings dominate the platform?
Which genres are the most common?
Which countries contribute the most content?
What information can users quickly retrieve about a specific title?

cannot be answered efficiently using raw data alone.

🎯 Goal of the Dashboard

The dashboard was developed to provide an intuitive and interactive platform that enables users to:

Explore Netflix's content catalog.
Analyze trends in Movies and TV Shows.
Compare content ratings and genre distribution.
Discover geographical availability of Netflix content.
Retrieve detailed information about individual titles.

📊 Content Strategy

Understand how Netflix has expanded its content library over time and identify periods of significant growth.

Analyze content ratings to understand which audience segments Netflix primarily targets.
